# Universal Timer 🌍⏳

Universal Timer is a high-precision, professional-grade productivity suite for Android. It combines a versatile countdown timer, a precise stopwatch with lap support, and a comprehensive global world clock—all in one beautifully designed, localized package.

## ✨ Features

### ⏲️ High-Precision Timer
*   **Custom Durations**: Set timers for any duration with minute and second precision.
*   **Quick Presets**: 1m, 5m, and 10m buttons for instant starts.
*   **Reliable Alarms**: Choice of multiple alarm tones (Classic, Radar, Beep, Gentle) that play even if the app is in the background.

### ⏱️ Professional Stopwatch
*   **Precision Timing**: Uses system clock deltas for millisecond accuracy, eliminating timer drift.
*   **Lap Support**: Record multiple laps with a single tap. Laps are displayed in a clean, organized list with timestamps.
*   **Dynamic Visuals**: Responsive circular progress ring that complements the digital display.

### 🗺️ Global World Clock
*   **70+ Cities**: Track time across a massive database of world regions.
*   **Favorites System**: Choose up to 5 favorite cities to display on your main screen.
*   **Automatic Sorting**: Cities are sorted alphabetically for quick and easy navigation.

### 🌍 Global Localization
*   **25+ Languages**: Full, professional translations for English, Spanish, French, German, Chinese, Japanese, Arabic, Hindi, and many more.
*   **Auto-Detection**: Automatically follows your phone's system language or allows for manual override in settings.

### 🎨 Personalization & UX
*   **Theme Switching**: Support for Light Mode, Dark Mode, and System Default themes.
*   **Settings Hub**: Centralized configuration for alarm sounds, language, and appearance.
*   **Modern Material 3 Design**: Built with Jetpack Compose for a smooth, responsive, and accessible experience.

## 🛠️ Tech Stack
*   **Language**: Kotlin
*   **UI Framework**: Jetpack Compose (Material 3)
*   **Architecture**: MVVM with StateFlow
*   **Async Processing**: Kotlin Coroutines
*   **Dependency Injection**: ViewModel with AndroidViewModel support
*   **Build System**: Gradle (KTS)

## 🚀 Getting Started
1. Clone this repository.
2. Open the project in **Android Studio (Ladybug or newer)**.
3. Build and run on an Android device or emulator (API 26+).
